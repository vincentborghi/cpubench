# cpubench

Interactive CPU benchmark comparison chart for desktop and laptop processors (Intel Core, Intel N-series, and AMD Ryzen).

## Features

- **Interactive charts** with custom bar visualizer.
- **Metric switching**:
  - PassMark CPU Mark (Multi-Thread)
  - Geekbench 6 (Multi-Core)
  - Geekbench 6 (Single-Core)
- **Reference CPUs** comparison with dynamic percentage offsets.
- **Filtering** by Brand, Power Consumption (TDP), Windows 11 compatibility, and RAM support.

## Live Demo

The benchmark is available live via GitHub Pages:
https://vincentborghi.github.io/cpubench/

## Usage

Simply open `index.html` in any modern web browser or visit the live link above.
