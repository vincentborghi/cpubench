cpubench — CPU Performance Comparison (Mini PCs and Laptops)

Compare desktop and laptop CPUs in real-time. Pin models (📌) to set comparison baselines that stay permanently visible across all filters. Use 📌 Pinned Only for a clean baseline dashboard or ⚡ Vs Pinned on any processor to compare it instantly. Badges indicate Power Consumption (⚡ Low Power ≤15W / ⚡ Normal Power >15W), RAM support (DDR4, DDR5, DDR4/5) and Windows 11 compatibility (✓ W11 / ✗ W11). Project by vincentborghi.
